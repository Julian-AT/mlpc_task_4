<threat_model>
## Threat Model

| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T-01-05 | Missing annotators are counted as negative votes, suppressing positives and corrupting all later model labels. | high | Unit-test NaN and all-zero inactive annotator slices; vote only over valid annotators. |
| T-01-06 | Cache omits IDs/timing/class names needed for splits, temporal context, and case studies. | high | Cache schema must include features, labels, file IDs, collector IDs, segment indices, start/end times, class names, and feature keys. |
| T-01-07 | Sanity checks leak raw dataset content into git. | medium | Log only aggregate counts, rates, feature dimensionality, feature keys, and paths; never log raw audio or feature arrays. |
</threat_model>

<feature>
  <name>Majority-vote label aggregation and dataset cache</name>
  <files>src/data.py, tests/test_data.py, results/log.md</files>
  <behavior>
    Given `annotations` shaped `[T, C, A]`, `aggregate_labels` binarizes values at `0.5`, masks inactive annotators, and returns `[T, C]` uint8 labels by majority vote over valid annotators.
    Cases:
    - One annotator: labels equal that annotator's binarized values.
    - Three annotators: two positive votes produce a positive label.
    - NaN-only annotator slice is ignored.
    - All-zero inactive annotator slice is ignored when at least one annotator has evidence.
    - Invalid shape raises `ValueError`.
  </behavior>
  <implementation>
    Extend `src/data.py` with `aggregate_labels`, cache schema helpers, `build_dataset(cache_path=None)`, sanity-check summary generation, and `if __name__ == "__main__": build_dataset()` for the dataset smoke command.
  </implementation>
</feature>
