\maketitle

This report trains and evaluates segment-level multi-label classifiers for the KIAL domestic sound event dataset. Starting from the Task 3 analysis, we convert the $[T,C,A]$ annotator overlap tensors into binary labels, create leakage-controlled train/validation/test splits, normalize and contextualize the 960-dimensional audio features, and compare a linear one-vs-rest classifier against neural networks. The final logistic regression reaches 0.529 test macro AP, while a validation-selected MLP ensemble reaches 0.638 test macro AP and 0.754 test micro AP, a tenfold improvement over the class-prior baseline in macro AP.

\needspace{6\baselineskip}
\section{Dataset Preparation}

\subsection{Label Aggregation}

Each feature file contains an annotation tensor $\mathrm{ann}\in[0,1]^{T\times C\times A}$ with one-second segments, 15 classes, and a variable number of annotators. We first remove annotator slices that contain no finite nonzero annotation information, then binarize each remaining annotator's overlap at 0.5. The final target for segment $t$ and class $c$ is majority vote:
\[
y_{t,c}=\mathbf{1}\!\left[
\frac{1}{A}\sum_{a=1}^{A}\mathbf{1}[\mathrm{ann}_{t,c,a}\geq 0.5]\geq 0.5
\right].
\]
This maps $[T,C,A]$ to $[T,C]$ and matches the task's segment-level objective: a segment is positive only when at least half of it is covered by an event and at least half of the valid annotators agree. The advantage over a union rule is precision. Task 3 showed missed and confused labels, especially for polyphonic clips, so accepting every single-annotator event would inject many false positives. The limitation is recall: with two annotators, events marked by exactly one annotator vanish, which particularly hurts brief classes such as \texttt{light\_switch}.

\subsection{Leakage-Controlled Split}

The split is collector-disjoint, not segment- or file-random. We use grouped random splitting with 70\%/15\%/15\% target proportions, yielding 116{,}950 train segments from 2{,}553 files and 285 collectors, 25{,}733 validation segments from 548 files and 61 collectors, and 25{,}556 test segments from 555 files and 62 collectors. This prevents three leakage modes: adjacent segments from the same recording sharing background noise, recordings from the same collector sharing rooms and devices, and hyperparameters being tuned on the same distribution used for final reporting. Segments from the same recording and recordings from the same collector must therefore not appear in multiple splits.

Class distributions should remain similar because macro AP weights rare and frequent classes equally. Exact stratification is impossible under collector grouping, but Figure~\ref{fig:splits} shows that the split preserves the main prevalence pattern: \texttt{footsteps} and \texttt{running\_water} remain common, while \texttt{light\_switch}, \texttt{bell\_ringing}, and \texttt{window\_open\_close} remain rare. We accept small deviations, e.g. \texttt{microwave} being more common in validation, as the cost of avoiding leakage.

\subsection{Preprocessing}

We concatenate all 56 aggregated feature arrays from the 14 acoustic groups into a 960-dimensional vector. A standard scaler is fit on training segments only and then applied to validation and test. This is necessary because spectral centroid, power, mel bands, flatness, and MFCC-derived features have very different scales; without z-scoring, linear models and neural optimization are dominated by high-variance features. The final models use temporal context by concatenating two previous and two following segments from the same recording, with zero padding at file boundaries. This produces 4{,}800 input dimensions and lets a segment-level classifier exploit onset/offset evidence distributed across the 0.5\,s hop grid.

\needspace{6\baselineskip}
\section{Evaluation}

\subsection{Metric}

We select models by validation macro average precision (macro AP). AP is threshold-free, so it evaluates the probability ranking directly instead of depending on an arbitrary 0.5 decision threshold. Macro averaging is essential for this dataset because \texttt{footsteps} has 25{,}685 positive segments while \texttt{light\_switch} has only 1{,}047; micro AP would mainly reward performance on common, sustained events. We still report micro AP to describe overall segment-ranking quality.

\subsection{Baseline and Performance Ceiling}

The baseline predicts the empirical training prevalence of each class for every validation or test segment. It has no access to audio features and obtains 0.0636 test macro AP and 0.1207 test micro AP (Table~\ref{tab:final}). Perfect AP of 1.0 is the formal maximum, but the realistic ceiling is lower: Task 3 measured only moderate annotator agreement, and the weakest classes are exactly those with ambiguous boundaries or acoustic confusions, such as \texttt{light\_switch}, \texttt{door\_open\_close}, and \texttt{wardrobe\_drawer\_open\_close}.

\section{Experiments}

\subsection{Logistic Regression}

The first model class is a one-vs-rest linear logistic classifier with independent sigmoid heads. We trained it with AdamW on the normalized temporal-context features and varied four important hyperparameters: feature representation (single segment vs. context), learning rate, weight decay, and positive-class weighting. Context was the decisive factor: non-context runs stayed near 0.45 validation macro AP, while context runs reached 0.49. The best setting used context features, learning rate $3\cdot10^{-3}$, weight decay $10^{-4}$, and positive weights clipped at 10. Stronger class weighting improved rare-class recall but reduced ranking quality for common classes; no weighting improved micro AP but hurt macro AP.

\subsection{MLP and Ensembling}

The second model class is a feed-forward neural network with ReLU activations, dropout, AdamW, and class-weighted binary cross-entropy. We varied width/depth, dropout, learning rate, seed, and training duration. The best single checkpoint used hidden layers $[512,256]$, dropout 0.45, learning rate $10^{-3}$, and early stopping after 43 epochs, reaching 0.599 validation macro AP. Wider networks such as $[1024,512]$ were close but less consistent. Because several high-performing checkpoints made complementary ranking errors, we averaged predicted probabilities. A greedy eight-checkpoint ensemble raised validation macro AP to 0.618 and was selected as the final MLP.

\subsection{Model Comparison}

Both classifiers substantially outperform the baseline, but the MLP is the stronger model on every aggregate metric. Logistic regression already separates sustained sounds well, showing that the precomputed features are informative and that temporal context matters. The MLP adds nonlinear feature interactions and improves the difficult middle range of classes: \texttt{toilet\_flushing} rises from 0.581 to 0.770 AP, \texttt{window\_open\_close} from 0.135 to 0.370, and \texttt{bell\_ringing} from 0.274 to 0.450. The remaining gap is concentrated in rare transients and mechanically similar events.

\section{Case Study and Reflection}

\subsection{Qualitative Test Files}

We selected two held-out recordings using the final MLP probabilities and the majority-vote labels (Table~\ref{tab:cases}). File 000727 is a successful kitchen recording: the metadata describes starting a microwave, turning on water, and washing dishes. The model tracks all three active classes and reaches file-level F1 0.978 at threshold 0.5. File 000892 is a failure case from a mobile hallway recording with door opening, footsteps, a light switch, and a coat hanger. The model fires, but not on the correct class-time pairs, yielding F1 0.000.

\subsection{Strengths and Failure Modes}

The final model is reliable for sustained or spectrally distinctive events: \texttt{running\_water} (0.925 AP), \texttt{keyboard\_typing} (0.861), \texttt{vacuum\_cleaner} (0.847), and \texttt{microwave} (0.793). These classes produce long, repeated evidence across adjacent segments, so the context window and AP-based training objective work well. The weakest classes are \texttt{light\_switch} (0.108), \texttt{wardrobe\_drawer\_open\_close} (0.363), \texttt{window\_open\_close} (0.370), and \texttt{bell\_ringing} (0.450). Their errors follow three patterns: short transients are missed or shifted by one segment; door/window/wardrobe actions are confused because they share mechanical impact and hinge sounds; and rare classes have too little positive evidence for stable ranking. A raw-audio temporal model, focal loss, or post-processing with event-duration priors would be the most promising next step, but the current MLP already provides a robust feature-based detector for the development set.
